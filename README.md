# 字之勇者 · 失落的文字王國

遊玩網址：https://ican101-cmd.github.io/rune-quest/

以生字筆順練習進行戰鬥、解謎與水晶蒐集的冒險遊戲，適合手機及平板。

## 開始遊玩

家長先選擇版本、年級與六課生字，再開始六個區域的冒險。目前提供南一、康軒、翰林一年級至六年級上學期字庫。完成一字自動攻擊；寫錯一筆受到反擊。集齊六顆水晶後，挑戰以錯字複習為主的暮星文字魔龍。

進度保存在各自的瀏覽器，無需登入。不同裝置、瀏覽器或網址不會自動共用進度，可從遊戲說明匯出／匯入進度。

## 網站維護

純 HTML、CSS 與 JavaScript，入口為 `index.html`，無需建置或後端。GitHub Pages 使用 `main` 分支的根目錄。更新檔案並推送後，Pages 會自動重新部署。

本機可使用 `python3 -m http.server 8000`，再開啟 http://localhost:8000/ 。請透過 HTTP 開啟，以便載入各版本字庫。

## 戰鬥補給
傷藥 20 金幣，恢復 40 HP；起死回生丹 50 金幣，倒下後恢復 100 HP 並保留戰鬥進度。免費重試從本關第一隻怪物開始；魔龍戰整場重打。重打進度不重複發金幣，自由練習仍可賺取金幣。道具隨選課存檔，可匯出／匯入。

## 注音冒險
家長設定 →「一年級入門 · 注音冒險」可選擇共用的 37 符號題庫，依六組固定順序練習，每符號兩輪，共 74 次書寫。初學模式寫錯提示、不扣 HP；挑戰模式寫錯一筆扣 20 HP。兩種模式與國語課本各自存檔，重置僅影響選定模式。

第一輪帶字形及方向提示，第二輪預設隱藏字形；孩子仍可使用提示、示範或開啟字形。每寫完一符號攻擊一次，首次 +5 金幣、再次 +2 金幣。六種解謎皆不用語音。魔龍優先複習主線曾寫錯至少一筆的符號，至少 10 個不同符號，不足時隨機補足。

注音筆順來源、資料版本與使用條件見 [BOPOMOFO-SOURCES.md](curricula/BOPOMOFO-SOURCES.md)。聲調與拼音練習不包含在此版。
